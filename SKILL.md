# Oil Pastel Scribble

Turns a photo into a quick, casual oil pastel drawing: loose back-and-forth scribbles, white paper showing between strokes, colour that doesn't quite stay inside the lines. The person only needs to share a photo; they don't have to describe it.

## How to use it

- **If you can generate images:** make the image from the photo, following every rule below.
- **If you can't:** write the image prompt for them (the template at the end), ready to paste into an image model with the photo attached.

## Coloring

- Colour is laid down with quick, loose back-and-forth scribble strokes, never filled in smoothly.
- Leave visible white paper gaps between strokes. Coverage is uneven: dense in some areas, sparse and streaky in others.
- Stroke direction follows each shape and changes from area to area, not one diagonal everywhere.
- Colour doesn't line up perfectly with the shapes: in a few places it goes past the edge, in others it leaves an area unfilled.
- Thick, waxy, matte oil pastel texture. No smooth gradients, no airbrush blending, no glossy digital look.

## Lines and shapes

- Outlines are optional: a loose dark line only where it helps define a shape, not around everything.
- Edges are mostly firm with a few irregular spots. Never an even, repeating rough border, which reads as a filter.
- Simplify details so it reads as a quick hand drawing.
- People and animals keep a recognizable face with simple, real features: no cartoon smile, no blush circles.
- Meaningful text and logos stay legible.

## Composition

- Work out the main subject of the photo and draw only that, centred. Drop busy backgrounds.
- If the whole scene is the subject (a kitchen counter, an open fridge), keep the scene.
- Plain white paper background, no ground shadow, square 1:1.

## Keeping a series consistent

- If earlier images in the same conversation used this skill, match their style exactly.
- If the person attaches a real oil pastel drawing as a reference, match its stroke texture, pressure variation and paper grain.

## Common problems and the fix

| Looks like | Fix |
| --- | --- |
| Smooth, digital, airbrushed | Build all shading from visible, layered strokes; no gradients |
| Rough edges look like a filter | Most edges firm, only a few irregular spots |
| Grain is the same size everywhere | Vary pressure: thick in some places, thin with paper showing in others |
| Too realistic | Simplify into fewer colour shapes, fewer fine details |

When the person gives feedback, change only what they point out and keep everything else the same.

## Prompt template

```
Turn this photo into a loose, hand-drawn oil pastel illustration.

Coloring:
- Quick, loose back-and-forth scribble strokes, never filled in smoothly
- Visible white paper gaps between strokes; uneven coverage, dense in some areas, sparse and streaky in others
- Stroke direction follows each shape and changes from area to area
- Color goes past the edge in a few places and leaves small areas unfilled in others
- Thick, waxy, matte oil pastel texture; no smooth gradients, no airbrush, no glossy digital look

Lines and shapes:
- Outlines only where they help define a shape
- Edges mostly firm with a few irregular spots; never an even rough border
- Simplify details so it reads as a quick hand drawing
- Keep faces recognizable with simple, real features (no cartoon smile, no blush)
- Keep meaningful text or logos legible

Composition:
- Draw only the main subject of the photo, centered
- Plain white paper background, no ground shadow, square 1:1
```
