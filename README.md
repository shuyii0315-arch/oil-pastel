# Oil Pastel Scribble

Turn any photo into a loose, hand-drawn oil pastel illustration: a skill for ChatGPT, Claude and other AI agents.

Quick scribbled strokes, white paper showing through, colour that slips past the lines. Share a photo and it finds the subject on its own, so a whole series comes out in the same hand.

**Live page:** https://shuyii0315-arch.github.io/oil-pastel/

## Install

Give this to your agent:

```
Install the Oil Pastel Scribble skill for me.
1. Download https://shuyii0315-arch.github.io/oil-pastel/SKILL.md
2. Save it as oil-pastel-scribble/SKILL.md in this tool's skills folder:
   Claude Code: ~/.claude/skills/
   Codex: ~/.codex/skills/
   Cursor: ~/.cursor/skills/
   Other agents: .agents/skills/ in this project
3. Tell me where you saved it.
```

In ChatGPT or the Claude app, upload `oil-pastel-scribble.zip` in your skill settings.
